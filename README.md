# IDECheck

Интерактивная утилита на PowerShell для проверки готовности среды разработки и автоматизации создания проектов.

## Возможности

- Проверка наличия Python, Git и Visual Studio Code.
- Определение версий установленных инструментов.
- Вывод списка недостающих компонентов.
- Создание каталогов проектов.
- Проверка имени проекта на наличие недопустимых символов.
- Создание стартового файла.
- Открытие проектов в Visual Studio Code.

## Поддерживаемые расширения

- Python (.py)
- PowerShell (.ps1)
- Bash (.sh)
- Batch (.bat)
- YAML (.yaml)
- JSON (.json)
- Terraform (.tf)

## Системные требования

- Windows
- PowerShell 5.1 или выше

## Установка

Разместите каталог IDECheck внутри каталога,
предназначенного для хранения проектов.

Рекомендуемая структура:

```text
projects/
    IDECheck/
        IDECheck.ps1
        README.md
```

Новые проекты будут создаваться в каталоге projects.

## Запуск

Откройте PowerShell в каталоге IDECheck и выполните:

```powershell
.\IDECheck.ps1
```

Следуйте инструкциям в терминале.

## Планы развития

- Рефакторинг кода с использованием функций.
- Расширенная валидация имён проектов.
- Возможность выбора каталога для хранения проектов.
- Опциональная инициализация Git-репозитория.
- Проверка расширений Visual Studio Code.
